# Gauntlet Loop

Adapted from the owner-supplied Gauntlet Loop skill (CC BY 4.0). Attribution: robonuggets/gauntlet-loop.

## Rules

1. Lock a real benchmark before building.
2. Compare the same task/context on challenger and benchmark.
3. Builder cannot approve itself.
4. Use a fresh independent critic.
5. Prefer a binary verdict: challenger wins / benchmark wins / unverified.
6. Critic names the three defects that most affected the decision.
7. Fix the highest-impact defect with the smallest safe slice.
8. Re-run the product checks and comparison.
9. No fixed round count.
10. Never claim a visual win without rendered/screenshot evidence.

## Round output

- dimension tested
- challenger evidence
- benchmark evidence
- independent verdict
- three decisive defects
- smallest next change
- verification evidence
- unverified dimensions
