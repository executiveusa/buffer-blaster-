# UGC Creative Director

Use this procedure for Buffer Blaster creative strategy and production planning. It teaches the workflow; it does not grant provider credentials, spending authority, publishing authority, or permission to bypass existing gates.

## 1. Truth before style

Build a compact truth brief from the supplied product, URL, source assets, or campaign context:

- product/service and mechanism
- target customer
- sharp recurring pain or desired transformation
- offer / CTA
- factual proof available
- unsupported claims that must not appear
- platform, aspect ratio, duration, and brand constraints

Do not invent missing product facts.

## 2. Angle matrix

Generate 3–5 materially different concepts before scripting. For each angle record:

- pain/desire activated
- hook pattern
- one-sentence promise
- proof/demo beat
- emotional payoff
- CTA
- factual or creative risk

Prefer visible mechanisms and product-in-use evidence over cosmetic style variations.

## 3. Continuity card

Before multi-shot UGC, lock:

- creator identity and age range
- wardrobe / hair / identifying traits
- environment and lighting
- product variant, packaging, orientation, scale
- framing/camera family
- voice / emotional state
- product-hand interaction rules
- negative constraints that must not drift

## 4. Storyboard before expensive generation

For every beat specify:

- timestamp / duration
- purpose
- spoken line and on-screen copy
- creator action
- product action
- framing / camera motion
- environment / light
- continuity carry-over
- transition to next beat

The opening beat must earn the next seconds before background explanation.

## 5. Provider-neutral execution plan

Translate approved beats into a provider-independent contract:

- input assets
- target duration / ratio / output format
- shot prompt
- continuity/reference inputs
- expected output
- QA check
- bounded retry rule

Provider adapters can translate this into Fal, Higgsfield, or another generator. Do not make Buffer Blaster dependent on a volatile provider model name.

## 6. Pre-spend gate

Before a paid generation, show:

- selected angle
- storyboard/script
- provider route when known
- estimated credit/cost boundary when available
- unsupported assumptions
- approval required

No-spend planning must remain usable without a paid media call.

## 7. Adversarial QA

The builder does not approve its own release candidate when an independent reviewer is available. The critic checks:

- pain clarity on first impression
- truthfulness
- hook strength
- product visibility
- creator/product continuity
- pacing/dead time
- mobile legibility
- platform/aspect fit
- unsupported claims
- CTA clarity
- whether the new candidate actually improves the benchmarked dimension

Return the three highest-impact defects first.
