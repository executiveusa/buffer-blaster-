# PROVEN-BETTER-NEW CARD — Buffer Blaster Private Install V2

Instinct: A small brand, agency, or operator wants an AI ad factory that becomes part of its own operating system instead of another monthly creative SaaS subscription.

Primary analog set: Adpanel / Creatify / Predis / Buffer for paid creative-and-publishing behavior; TryPost for self-hosted programmatic infrastructure; Arcads / MakeUGC / MaxFusion for public category clarity and proof-first landing behavior.

## Proven — keep

- **Fast category comprehension.** Existing AI ad tools lead with the output: create ads, create AI videos, create UGC. Buffer Blaster should say what it does before explaining architecture.
- **Create → review → publish/learn is already paid behavior.** Adpanel, Predis, Creatify, and Buffer demonstrate that buyers pay for creative generation, workflow, approvals, publishing, and API access. We do not need to invent those jobs.
- **Programmatic access is baseline infrastructure, not the headline.** REST/MCP/CLI make the install operable by agents, but they should support the offer rather than replace it.
- **Self-hosted and operator-controlled infrastructure is a real implementation pattern.** TryPost and the open-source media gateways reviewed in the universal video gateway research show that production workflows can be deployed under operator control instead of forcing every function into one SaaS vendor.
- **Proof beats explanation.** The landing page should show finished video output before deep workflow copy.

## Better — test

- **Ownership instead of subscription stacking.** The proposed advantage is not "more models." It is one private ad-factory install that can keep working while model vendors change. Atomic test: ask five agencies/brands currently paying for two or more creative tools whether a one-time owned install is more attractive than adding another monthly seat.
- **Provider-neutral execution.** The same approved UGC job can select different configured gateways/models without changing factory business logic. Atomic test: run the same brief through two configured providers and compare cost, acceptance rate, and operator edits.
- **Governed cost before generation.** Buffer Blaster exposes model/provider selection and estimate checks before wallet reservation. Atomic test: ten real jobs; verify no paid render begins without a verified estimate, active allowance, and explicit approval.
- **Agent-ready without shadow workflows.** The browser, REST, MCP, and CLI should resolve to the same backend contracts. Atomic test: a cold agent and a human operator each plan the same job and produce equivalent receipts.

## New — quarantine until proven

- **One-time private-install commercial model.** This is the current product hypothesis, not established willingness-to-pay. Atomic test: quote at least five real prospects and record close/no-close, price objection, deployment objection, and which included capability mattered.
- **Multi-gateway model fleet.** Useful plumbing only if it reduces cost or improves accepted output. Atomic test: track cost per accepted shot by provider/model instead of celebrating catalog size.
- **Automatic per-shot routing.** Do not market this as finished until quality telemetry can select a provider/model using real acceptance history.
- **Voice and autonomous agents.** Keep as alternate controls. They are not allowed to bypass approval or become the reason the landing page is hard to understand.

## Graveyard / anti-signal

The primary risk is feature-suite sprawl: mature tools already offer avatars, generation, editing, scheduling, analytics, and APIs. "We have more features/models" is not a protected position.

Do not use:
- founder excitement;
- number of integrations;
- model-count screenshots;
- prior engineering effort;
- "AI agent" novelty

as evidence that buyers want the install.

Useful evidence is:
- prospects agreeing to a one-time install;
- time to first finished ad;
- cost per accepted shot;
- number of recurring SaaS tools displaced;
- operator corrections per job;
- successful handoff to the client's own infrastructure.

## Commercial decision for V2

Retire the V1 public monthly tier hypothesis ($39/$119/$299 per month) from the public offer.

Public offer:

**Buffer Blaster Private Install**
- one-time implementation fee;
- dedicated deployment;
- provider-neutral model gateway;
- operator-owned provider/API credentials;
- Studio + REST + MCP + CLI;
- approval and spend controls;
- documentation + rollback + handoff.

Not included in the one-time fee unless explicitly scoped:
- third-party model/API usage;
- cloud hosting;
- paid media;
- ongoing managed creative service;
- future custom integrations/support.

Exact one-time price remains a sales hypothesis until real install quotes are tested.

## Landing-page contract

1. **Outcome:** Own the system that turns products into ads.
2. **Proof:** playable real Buffer Blaster output.
3. **Mechanism:** product → angle → model route → ad/evidence.
4. **Difference:** model/provider choice stays replaceable and operator-controlled.
5. **Offer:** one-time private install, not monthly Buffer Blaster SaaS.
6. **CTA:** Request an install.
