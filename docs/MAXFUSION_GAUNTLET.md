# MaxFusion + Collins Final Gauntlet

## Named bar
- Product/category clarity: https://maxfusion.ai/
- Agent/MCP clarity: https://maxfusion.ai/mcp
- Design/brand rigor: project Collins-Level Website Design Protocol
- Product doctrine: HEART_AND-SOUL.md

Do not copy MaxFusion's visual identity, claims, actors, layouts, assets, or pricing. Extract principles and compare outcomes.

## Blind comparison questions
A reviewer who did not build Buffer Blaster must compare equivalent desktop and mobile screenshots and answer:

1. Which product can a first-time creative operator explain more accurately after five seconds?
2. Which makes the complete workflow easier to understand without reading implementation language?
3. Which feels more credible as serious creative infrastructure rather than an AI wrapper?
4. Which communicates agent access most clearly?
5. Which makes human control, approvals, and cost boundaries easier to trust?
6. Which mobile experience has the clearer hierarchy and shortest useful path?
7. Which experience feels more distinctive and ownable rather than template-derived?
8. What is the single biggest gap preventing Buffer Blaster from matching the bar?

## Buffer Blaster must win on its own wedge
It does not need feature parity with MaxFusion. It must clearly own:
- private client creative infrastructure;
- managed or dedicated deployment;
- one governed system for humans and agents;
- server-owned budget limits;
- self-hosted/sovereign persistence when required;
- client-scoped commerce, paid-media, and publishing adapters;
- evidence attached to creative work without fabricated performance.

## Collins acceptance
Reject the release if any of these remain:
- unclear primary audience or job;
- conflicting product names;
- low-ticket pricing presented as the core offer;
- generic AI/SaaS language;
- unsupported performance claims;
- card/pill density that overwhelms hierarchy;
- mobile overflow, unreadable text, or weak touch targets;
- inaccessible focus/contrast;
- no clear action after comprehension;
- builder self-approval without an independent screenshot review.

## Exit
The final pass is complete only when:
- repo CI is green;
- independent reviewer chooses Buffer Blaster or declares the gap non-critical within Buffer Blaster's narrower private-infrastructure position;
- Collins release requirements have zero critical failures;
- production walk tests for REST/MCP/CLI pass;
- the exact reviewed SHA is deployed and smoke-tested.
