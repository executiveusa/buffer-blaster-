# 04 Generate

## Preconditions
Research truth, scripts, prompts, and casting direction have passed their gates.

## Sequence
1. Submit clip 1 through the configured media provider.
2. Measure/trim clip 1 dead-air tail before selecting a continuation frame.
3. Extract the final clean frame: still subject, eyes open, stable composition.
4. Use that frame as the visual seed/reference for clip 2 when the configured provider supports image-conditioned video.
5. Preserve the same environment, lighting, creator identity, framing intent, and voice direction.

## Rules
- Provider/model IDs come from environment configuration.
- Do not spend on a prompt whose gate failed.
- Record provider request IDs and cost receipts when available.

## Output
Clip 1, seed-frame reference, clip 2, and generation receipts.
