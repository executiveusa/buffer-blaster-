# Proof-First Money Loop — Experiment Template

One repeatable unit: a measured creative/business experiment linked to a Hermes opportunity and, when applicable, a Buffer Blaster campaign.

## Pipeline

`01_define -> 02_bind_channels -> 03_launch -> 04_ingest -> 05_decide -> 06_handoff`

The filesystem is the human-editable control surface. Supabase is the concurrent runtime ledger for provider events. Do not duplicate raw provider payloads into ICM; write normalized evidence summaries and stable IDs/links.

## Ownership

- Hermes/Pauli: opportunity, prospect, commercial constraint, CLOSE/COMPOUND.
- Buffer Blaster: proof asset, experiment execution, normalized measurement, winner decision.
- Human: approval before launch/spend/publish and any contractual commitment.

## Status

Status is the highest numbered stage with its required output artifact present. A later stage must not run without the previous stage's output and required human approval.
